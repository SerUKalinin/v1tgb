# 🔴 АРХИТЕКТУРНЫЕ ОГРАНИЧЕНИЯ (ЖЁСТКИЕ)

## Risk Engine:

- ❌ не имеет IO
- ❌ не вызывает внешние API
- ❌ не пишет в БД
- ✔ только детерминированные вычисления

## Execution:

- ❌ не содержит бизнес-логики
- ✔ только адаптер биржи

## Strategy:

- ❌ не знает про биржу
- ❌ не делает HTTP / DB calls
- ✔ чистая функция:
  Decision decide(MarketSnapshot, PortfolioState)

## OMS:

- ✔ source of truth

# 📊 FINAL DEFINITION OF DONE

Система готова к Stage 4 ТОЛЬКО ЕСЛИ:

- Risk полностью контролирует execution path
- нет обхода Risk
- Outbox (если есть) гарантирует delivery
- Strategy полностью изолирована
- Execution идемпотентен
- нет потери событий
- система устойчива к retry/recovery
